# Fact Opinion Check

## Overview

对用户提供的文本进行事实与观点拆分，并核查每条事实或观点是否能被相关权威新闻报道支持。输出只保留分析结果，不添加解释、建议、免责声明或额外总结。

## Workflow

1. 读取用户提供的文本内容，忽略包裹文本的提示词、引号和占位符。
2. 提取作者声称的事实。事实是可被外部证据验证真假的具体断言，包括人物、组织、时间、地点、事件、数字、因果、政策、判决、公告、交易、伤亡、排名、引用来源等。
3. 提取作者表达的观点。观点是评价、判断、推测、立场、价值判断、归因解释、趋势预测、主观形容或结论性表达。
4. 使用权威新闻报道核查每条事实和观点的证据支撑。优先检索新华社、央视新闻、人民日报、BBC、Reuters、AP、The New York Times、The Washington Post、The Guardian、Financial Times、WSJ、Bloomberg、官方机构公告或大型主流媒体报道；排除自媒体、个人博客、营销号、论坛、未署名搬运站和仅聚合内容。
5. 标注证据状态：
   - 事实能在权威来源中找到直接或高度一致证据时，标注`（有证据）`
   - 观点有可靠事实链条或权威报道明确支持其核心判断时，标注`（有证据）`
   - 找不到权威报道、只有自媒体来源、证据只支持部分无关内容、或证据不足以支撑原句核心含义时，标注`（无证据）`
6. 若高优先级系统要求提供来源链接，则在满足来源要求的同时保持输出尽量短；否则不要额外输出来源列表。

## Output Format

按下面格式输出，不添加其它内容：

```text
作者声称的事实：
事实1（有证据）
事实2（无证据）

作者表达的观点：
观点1（有证据）
观点2（无证据）
```

如果没有可识别事实或观点，对应部分输出`无`。

## Prompt Template

当用户只给出任务名称或要求套用提示词时，按以下模板执行：

```text
对下面的[文本内容]进行分析，目标是提取其中的事实和观点，不需要输出其它内容。
先列举作者声称的事实，每条一行，并核查这些事实能否在相关权威新闻报道中找到（排除所有自媒体），根据核查结果，在每条事实的后面注明（有证据）或（无证据）。
然后列举作者表达的观点，每条一行，并根据这些观点是否有证据支撑，在每个观点的后面注明（有证据）或（无证据）。

[文本内容]：
'''
{用户提供的文本}
'''
```
