# Draw Folk Doodle Image

Claude Code 入口说明：用于童趣民间涂鸦风格的图片生成或图片编辑，不用于工程图表。

## 与其他 draw skill 的区别

| Skill | 适用场景 | 产物 | 不适合 |
| --- | --- | --- | --- |
| `draw-folk-doodle-image` | 用户给图或描述场景，要求民间插画、涂鸦风、童趣、可爱手工感 | 彩色平面插图，白纸背景，装饰性涂鸦元素 | 严肃工程图、克制黑线橙色 editorial 图 |
| `draw-crochet-doll-image` | 指定图片或对象转温馨钩针玩偶、毛线公仔 | 柔软纱线质感、可见针织细节的怀旧毛公仔 | 平面民间涂鸦、白纸装饰插图 |
| `draw-orange-line-illustration` | 单一观点、隐喻、文章配图或封面 | 黑线白底、一个橙色重点的概念插画 | 大胆彩色、童趣装饰风 |
| `draw-hand-drawn-infographic` | 把内容压缩成 3-6 点手绘总结图 | 16:9 手绘卡通信息图，含短文字 | 只做图片风格转换 |
| `draw-archify` | 架构图、流程图、时序图、数据流图、生命周期图 | 可导出的独立 HTML 工程图表 | 任何插画风格化图片 |

## Claude 使用要点

- 用户提供图片时保留主体和构图逻辑，只替换成民间平面涂鸦风
- 用户只描述场景时，直接按同一风格生成新图
- 避免写实、3D、复杂光影、贴近原图配色和长文字
