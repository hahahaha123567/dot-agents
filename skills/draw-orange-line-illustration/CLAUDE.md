# Draw Orange Line Illustration

Claude Code 入口说明：用于克制的 editorial 概念插画，不用于多要点信息图或工程图。

## 与其他 draw skill 的区别

| Skill | 适用场景 | 产物 | 不适合 |
| --- | --- | --- | --- |
| `draw-orange-line-illustration` | 文章配图、封面图、PPT 配图、单一观点隐喻 | 黑线白底、大留白、仅一个橙色重点的概念插画 | 彩色童趣图、多点总结、工程结构图 |
| `draw-crochet-doll-image` | 指定图片或对象转温馨钩针玩偶、毛线公仔 | 柔软纱线质感、可见针织细节的怀旧毛公仔 | 黑线白底 editorial 概念插画 |
| `draw-hand-drawn-infographic` | 把内容总结成 3-6 个要点 | 16:9 手绘卡通信息图 | 只表达一个隐喻或情绪 |
| `draw-folk-doodle-image` | 图片或场景转童趣民间涂鸦风 | 彩色平面装饰插图 | 克制黑白线稿 editorial 风 |
| `draw-archify` | 架构、流程、时序、数据流、生命周期 | 可导出的独立 HTML 工程图表 | 概念插画 |

## Claude 使用要点

- 每张图只表达一个概念张力，优先设计隐喻再写生成提示
- 保持黑线、纯白背景、大留白、唯一橙色 `#F97316`
- 人物要小，主体物件要大，避免把画面做成多元素说明图
