# Draw Crochet Doll Image

Claude Code 入口说明：用于把指定图片或描述对象转换成温馨钩针玩偶、毛线公仔风格，不用于工程图表或普通平面插画。

## 与其他 draw skill 的区别

| Skill | 适用场景 | 产物 | 不适合 |
| --- | --- | --- | --- |
| `draw-crochet-doll-image` | 用户给图或描述对象，要求玩偶风、钩针角色、毛线玩偶、毛公仔、amigurumi | 柔软纱线质感、可见针织细节、怀旧手工毛公仔 | 工程图表、扁平民间涂鸦、黑线概念插画 |
| `draw-folk-doodle-image` | 图片或场景转童趣民间涂鸦风 | 彩色平面装饰插图，白纸背景 | 真实毛线材质和立体玩偶质感 |
| `draw-orange-line-illustration` | 单一观点、隐喻、文章配图或封面 | 黑线白底、一个橙色重点的概念插画 | 可爱毛绒玩偶或材质转换 |
| `draw-hand-drawn-infographic` | 把内容压缩成 3-6 点手绘总结图 | 16:9 手绘卡通信息图，含短文字 | 只做图片风格转换 |
| `draw-archify` | 架构图、流程图、时序图、数据流图、生命周期图 | 可导出的独立 HTML 工程图表 | 任何图片风格化或玩偶化 |

## Claude 使用要点

- 优先保留源图主体、姿态、关键配色和标志性配件
- 把真实材质改成柔软纱线、可见针脚、圆润填充感和手工缝线
- 按用户提示词填充 `[subject]`、`[color1]`、`[color2]`、`[prop]`、`[setting]`
- 避免塑料玩具、3D 亮面、瓷娃娃、黏土手办和写实皮肤
