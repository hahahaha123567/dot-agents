# Draw Hand-Drawn Infographic

Claude Code 入口说明：用于把一段内容总结成手绘卡通信息图，不用于技术拓扑精确绘制。

## 与其他 draw skill 的区别

| Skill | 适用场景 | 产物 | 不适合 |
| --- | --- | --- | --- |
| `draw-hand-drawn-infographic` | 用户要“信息图 / 手绘图 / 画一张图总结 / doodle summary” | 16:9 手绘卡通信息图，3-6 个短要点 | 精确架构图、单一隐喻插画、图片风格转换 |
| `draw-crochet-doll-image` | 指定图片或对象转温馨钩针玩偶、毛线公仔 | 柔软纱线质感、可见针织细节的怀旧毛公仔 | 多点内容总结、信息图 |
| `draw-archify` | 架构、流程、时序、数据流、状态生命周期 | 独立 HTML 工程图表 | 卡通总结、观点海报 |
| `draw-orange-line-illustration` | 单一概念隐喻、文章配图、封面图 | 黑线白底、一个橙色重点的概念插画 | 多点总结型信息图 |
| `draw-folk-doodle-image` | 图片或场景转童趣民间涂鸦风 | 彩色平面装饰插图 | 含结构化要点的信息图 |

## Claude 使用要点

- 先从用户内容提炼 3-6 个关键词或短句
- 保持 16:9 横版、大量留白、手绘文字和手绘标注
- 输入涉及版权角色时改成视觉相近但无版权问题的替代形象
